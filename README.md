# Intelligence Agency (Intelligence Sales CRM)

Plateforme CRM & Landing page B2B intelligente adaptée au marché marocain et international.

## 🚀 Fonctionnalités Clés
- **Landing Page B2B Moderne** : Présentation des offres IA, KPIs en direct, intégration interactive.
- **Pipeline des Ventes (Kanban)** : Suivi dynamique des leads et opportunités (Leads, Qualification, Discovery, Proposal, Negotiation, Won, Lost).
- **Gestion des Devis & Propositions (Quotes)** : Génération rapide des devis chiffrés en MAD (د.م.), calcul de TVA, remises, et liaisons directes avec les opportunités.
- **Workflow de Validation** : Approbation des remises managériales et enregistrement des confirmations clients (Bons de commande).
- **Multilingue & RTL** : Support complet Anglais et Arabe avec direction RTL automatique.
- **Agents IA & Analytics** : Détection des leads à haut potentiel et recommandations stratégiques.

## 🛠️ Stack Technique
- **Front-end** : React, Vite, Tailwind CSS, Lucide Icons, Framer Motion
- **Back-end** : Structure modulaire prête pour les API REST

## 📦 Installation & Démarrage

```bash
# Aller dans le dossier front-end
cd front-end

# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev

# Compiler pour la production
npm run build
```
