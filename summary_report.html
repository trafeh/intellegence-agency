1. Executive Summary Overview

Intelligence Sales (v-1) is an all-in-one commercial intelligence web platform engineered to transform traditional B2B sales cycles. It bridges a high-converting public corporate portal with an operational CRM delivering strict commercial governance:

🛡️ 7-Day Inactivity Rule
Strict algorithmic enforcement ensuring zero forgotten leads. Any opportunity untouched for 7 days triggers proactive WhatsApp and Email re-engagement workflows.
🤖 7 AI Specialized Agents
Human-in-the-loop multi-agent orchestration for lead qualification, deal closing, objection handling, pricing governance, and client expansion.
🇲🇦 Moroccan Market Tailored
Native formatting for Moroccan Dirhams (MAD), ICE commercial identifiers, VAT (TVA 20%), and bilingual Casablanca Marina corporate defaults.
🌐 Native Trilingual (EN / FR / AR)
Full instant translation engine across all landing and CRM modules with automatic Right-to-Left (RTL) visual mirroring for Arabic.
2. Technology Stack & Core Architecture Specs
Layer Framework / Tool Implementation Details
Frontend Core React 19 + Vite 8 Single-Page Architecture with client routing via react-router-dom. Zero-lag page transitions.
Styling System Tailwind CSS v4 Customized @theme tokens, deep navy dark palette (#050b16, #081120), and unified rounded-lg container borders.
Data Visualization Recharts Library Interactive Revenue Trajectory (AreaChart), Funnel Stage Distribution (BarChart), and Lead Quality health (Donut chart).
State Management React Context API Decoupled reactive layers: CrmContext, AuthContext, ThemeContext, and LanguageContext.
Icons & Assets Lucide React + WebP/PNG Complete iconography with dark/light dynamic theme switching and adaptive RTL rotation.
Design System Standard (v-1): All main container boundaries (cards, tables, chart boxes, modal panels) have been standardized to refined rounded-lg and rounded-md radii, eliminating bulky 3xl corners while keeping action buttons distinct.
3. CRM Functional Modules (Commercial Suite) Module Breakdown
Module Core Functionality Key Highlights & Automation
Executive Cockpit
(CrmDashboard)		 Executive KPI tracking, revenue trends, and AI suggestions feed.
  • Actuals vs Quota vs AI Predictive Trajectory.
  • Stage distribution bar chart with 1-click pipeline filtering.
  • Dual mode: Executive Director vs Sales Rep personal view.
Deals Pipeline
(CrmPipeline)		 4x4 structured commercial Kanban board across 7 sales stages.
  • Stages: Discovery, Qualification, Proposal, Negotiation, Closing, Won, Lost.
  • Compact number formatting (K / M / B MAD).
  • Comprehensive deal diagnosis & interactive modal inspection.
Predictive Leads
(CrmLeads)		 Multi-channel inbound lead triage and qualification scoring.
  • Scoring categories: Hot 🔥, Warm ⚡, and Cold ❄️.
  • Automated reasoning notes generated for each lead.
  • 1-Click Deal Conversion directly into active pipeline.
Quotation Engine
(CrmQuotes)		 Commercial proposal (Devis) builder with discount governance.
  • Automatic VAT (20%) and margin calculations.
  • Strict rule: discounts > 15% trigger Director approval flag.
  • Printable Formal Proposal (Devis) with ICE & legal footer.
Follow-Up Engine
(CrmActivities)		 Strict 7-Day inactivity detection & multi-channel outreach.
  • Identifies all deals with 7+ days without touchpoint.
  • Auto-drafts tailored re-engagement messages in FR & AR.
  • 1-click execution to WhatsApp or Email with human review.
7 AI Agents Center
(CrmAiAgents)		 Specialized sales multi-agent command hub.
  • Agents: Lead Qualifier, Closer, Objection Solver, Pricing, etc.
  • Live interactive prompt console with streaming replies.
  • Human-in-the-Loop active governance watermark.
B2B Account Ledger
(CrmAccounts)		 Corporate customer registry with credit monitoring.
  • Tiering: Strategic Tier A, Mid-Market Tier B, Standard Tier C.
  • Credit line tracking and authorized debt thresholds.
  • Decision-maker directory with direct phone/email triggers.
Sales Quota & Team
(CrmTeam)		 Global quarterly targets and sales rep performance leaderboards.
  • Real-time rep target completion percentage bar.
  • Calculated commissions earned and pipeline volume per rep.
